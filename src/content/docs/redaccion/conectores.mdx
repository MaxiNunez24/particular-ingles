Un texto no es una lista de frases sueltas. Lo que hace que se lea bien son los **conectores**:
las palabras que dicen **en qué orden** pasan las cosas y **cómo se relacionan** (*pero*,
*porque*, *así que*…).

Esta es la ayuda que vas a tener a mano en todas las redacciones. Tocá 🔊 para escuchar cada
ejemplo.

<Conectores />

:::tip[Cómo usarlos en un texto sobre una rutina]
1. Arrancá con **First,** y seguí con **Then,** / **After that,**: así el texto va en orden.
2. Usá **and** para juntar dos cosas que hacés seguidas.
3. Usá **but** para mostrar una diferencia (*I get up early, but my brother gets up late*).
4. Usá **because** para dar una razón.
5. Terminá con **Finally,**.

Después de *First, Then, After that, Finally* va una **coma**.
:::

  titulo="¿Qué conector va?"
  fundamental

  items={[
    { f: "{*First|Finally|Because}, I get up and have a shower.", e: '<b>First</b> = primero: así arranca la rutina.' },
    { f: "I have breakfast. {*Then|But|Because}, I leave home.", e: '<b>Then</b> = después: sigue el orden.' },
    { f: "I walk to school {but|*because|so} it's near my house.", e: '<b>because</b> = porque: da la razón.' },
    { f: "I like English, {*but|so|because} I don't like History.", e: '<b>but</b> = pero: una diferencia.' },
    { f: "My mum works late, {because|*so|but} we have dinner at 10.", e: '<b>so</b> = así que: la consecuencia.' },
    { f: "{*When|But|So} I get home, I make a snack.", e: '<b>When</b> = cuando.' },
    { f: "My dad cooks dinner and he {*also|because|but} washes the dishes.", e: '<b>also</b> = también (va antes del verbo).' },
    { f: "{Then|*Finally|First}, I go to bed at 11.", e: '<b>Finally</b> = por último: cierra el día.' },
  ]}
>
  Elegí el conector que tiene sentido. Leé la frase entera antes de elegir.
</Completar>
